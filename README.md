# minimp3-java

[![Maven Central](https://img.shields.io/maven-central/v/io.github.akivanno/minimp3-java)](https://central.sonatype.com/artifact/io.github.akivanno/minimp3-java)

A pure-Java MP3 decoder: a faithful port of [minimp3](https://github.com/lieff/minimp3) by lieff
(commit [`1428237`](https://github.com/lieff/minimp3/tree/142823796ab8efa55e1bf11406028f3be77ecceb)).

- MPEG-1, MPEG-2 and MPEG-2.5 Layer III, 8 to 48 kHz; mono, stereo, joint stereo (mid/side and
  intensity); CBR, VBR and free format; bit reservoir; skips ID3v2 tags and garbage like the original.
- **Bit-exact with the C code**: on every test file (the ISO conformance vectors, a synthetic corpus of
  157 files and thousands of corrupted streams) the Java decoder returns exactly the same frames and
  the same float samples as `minimp3.h` built with `MINIMP3_ONLY_MP3`, `MINIMP3_NO_SIMD` and
  `MINIMP3_FLOAT_OUTPUT`.
- **Safe on untrusted input**: no exception, no read outside the given range, linear time, no
  allocation driven by the data, whatever the bytes.
- **No dependencies**, Java 21+, no static mutable state, no allocation per frame, no reflection, no
  native code. One decoder per stream; decoders can run in parallel on different threads.
- About 1000× real time on one core of a recent laptop CPU (44.1 kHz stereo).

Layer I and II are not decoded (as with `MINIMP3_ONLY_MP3`). Tag parsing, duration, seeking indexes,
gain and clipping are left to the application.

## Usage

```java
import com.radiomod.mp3.Mp3Decoder;
import com.radiomod.mp3.Mp3FrameInfo;

Mp3Decoder decoder = new Mp3Decoder();
Mp3FrameInfo info = new Mp3FrameInfo();
float[] pcm = new float[Mp3Decoder.MAX_SAMPLES_PER_FRAME];

int pos = 0;
while (true) {
    int samples = decoder.decodeFrame(mp3, pos, mp3.length - pos, pcm, info);
    if (info.frameBytes == 0) {
        break;                       // no more data
    }
    pos += info.frameBytes;
    if (samples > 0) {
        // pcm[0 .. samples * info.channels): interleaved samples (L, R, L, R...) at info.hz,
        // not clipped: values can exceed [-1, 1]
    }
}
```

The API mirrors `mp3dec_t`, `mp3dec_init`, `mp3dec_decode_frame` and `mp3dec_frame_info_t`:

| C | Java |
|---|---|
| `mp3dec_init(&dec)` | `new Mp3Decoder()`, `decoder.reset()` |
| `mp3dec_decode_frame(&dec, mp3, bytes, pcm, &info)` | `decoder.decodeFrame(mp3, offset, length, pcm, info)` |
| `pcm == NULL` (read the frame header only) | `pcm == null` |
| `mp3dec_f32_to_s16(in, out, n)` | `Mp3Decoder.toPcm16(in, out, n)` |
| `MINIMP3_MAX_SAMPLES_PER_FRAME` | `Mp3Decoder.MAX_SAMPLES_PER_FRAME` |

The semantics are those of the original: `frameBytes == 0` means more data is needed; `frameBytes > 0`
with a result of 0 means bytes were skipped (a tag, garbage, a frame whose bit reservoir is missing);
otherwise the frame starts at `offset + frameOffset`. To start in the middle of a stream, jump to any
byte, call `reset()` and keep decoding: the decoder finds the next frame by itself, and the output
matches a decoding from the start after a few frames (see [NOTES.md](NOTES.md#75-restart-in-the-middle-of-a-file)).

The only exceptions are `NullPointerException` and `IllegalArgumentException` for invalid arguments
(`null` data or info, a range outside the array, `pcm` shorter than `MAX_SAMPLES_PER_FRAME`).

## Maven

```xml
<dependency>
  <groupId>io.github.akivanno</groupId>
  <artifactId>minimp3-java</artifactId>
  <version>0.1.0</version>
</dependency>
```

or with Gradle:

```kotlin
implementation("io.github.akivanno:minimp3-java:0.1.0")
```

The jar has the automatic module name `com.radiomod.mp3`.

## Building and testing

```
./gradlew check
```

compiles with `--release 21` and runs the tests on JDK 21 and JDK 25 (Gradle downloads the JDKs that
are missing). Most tests compare the port with the C original, so the first run prepares the test
data in `build/testdata` with [`reference/prepare_testdata.py`](reference/README.md), which needs
**Python 3, git, a C compiler (gcc or clang) and ffmpeg with libmp3lame**. Useful options:

| Option | |
|---|---|
| `-Pcc=/path/to/gcc`, `-Pffmpeg=…`, `-Ppython=…` | tools to use |
| `-Pminimp3=/path/to/minimp3` | an existing checkout of minimp3 at the pinned commit |
| `-PskipTestData` | run only the tests that need no generated data |
| `-PdiffFuzz=N` | number of corrupted streams decoded by both C and Java (default 600) |

Other tasks: `./gradlew benchmark` (decoding speed), `./gradlew jacocoTestReport` (coverage),
`./gradlew javadoc`. Test results, per-file comparisons and PSNR tables are written to
`build/reports/minimp3`.

All the audio used by the tests is free of copyright: the ISO conformance vectors of the minimp3
repository and synthetic signals (sweeps, noise, impulses, silence) generated by ffmpeg and encoded
with LAME. No audio file is stored in this repository.
